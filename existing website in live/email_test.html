Debug Instructions:
  1. Fill out the form and click "Send Test Email"
  2. Check the response message below
  3. Check mail_debug_log.txt in your root directory for detailed logs
  4. Common issues:
    • SMTP Connection Failed: Check if port 465 is open, try port 587
    • Authentication Failed: Verify email password in cPanel
    • SSL/TLS Error: Try switching between SMTPS (465) and STARTTLS (587)
